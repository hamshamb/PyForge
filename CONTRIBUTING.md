# Contributing to PyForge

Thank you for considering a contribution to PyForge.

## How to contribute

1. Fork the repository.
2. Create a separate branch for your change.
3. Make and test your changes.
4. Submit a pull request explaining what was changed.

Do not submit code, images, icons, fonts, or other content unless you have the
right to share them under compatible terms.

## Coding guidelines

- Keep the interface understandable for nontechnical users.
- Explain options in plain English.
- Test both source-code and frozen executable modes.
- Avoid adding unnecessary dependencies.
- Do not commit build output, virtual environments, secrets, or local settings.
